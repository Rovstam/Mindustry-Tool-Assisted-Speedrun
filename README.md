# Mindustry Tool Assisted Speedrun
This mod is for doing Tool Assisted Speedruns. Currently supports simple SaveStates (using the keybinds in the config), which pauses the game, saves the current state of the map and allows reloading it whilst the game is paused, and a New button in the Main menu for custom TAS savefiles (that does not modify any of your saves.)
